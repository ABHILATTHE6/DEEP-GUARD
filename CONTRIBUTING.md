# Contributing to DEEP-Guard

Thanks for contributing. Keep changes focused, reproducible, documented, and testable.

## Workflow

1. Create a focused branch from `main`.
2. Make the smallest coherent change.
3. Add or update tests when behavior changes.
4. Run formatting, linting, tests, and relevant ML evaluation locally.
5. Update documentation for user-facing or model-facing changes.
6. Open a pull request with a clear summary and validation notes.

## ML contributions

For model changes, document the dataset split, preprocessing, model version, training configuration, metrics, and known limitations. Never commit restricted datasets, credentials, or large model binaries unless explicitly approved and appropriate for the selected release mechanism.
